Pump.fun Sharpe Sprint: cleanest paper bot — a quiet-accumulation snipe bot for the make.fun bounty. It buys only calm, liquid bonding curves (last 10 trades within a 2% price range, at least 2 SOL of real reserves, net buying) and exits fast on a +15% take-profit, a -12% hard stop, or a -15% trailing stop, with a ~2 minute max hold. One filled entry per mint, max 5 open positions, zero external dependencies.

## Run it

```sh
node main.ts
```
